ValiTrack Mobile (Expo)

Rápido scaffold Expo para consumir a API do ValiTrack.

Instruções:

1. Instale dependências:

```bash
cd mobile-app
npm install
```

2. Iniciar o app (Expo):

```bash
npm start
# ou
expo start
```

3. Ajuste `src/api/client.js` `BASE_URL` conforme seu ambiente (emulador Android usa 10.0.2.2).

Observações:
- Esse é um scaffold mínimo. Posso adicionar navegação, telas de produto/fornecedor, autenticação e assets.
